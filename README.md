# Kahoot-bot
### Overview
This project will allow you to set up a bot that would join kahoot quiz with funny name and pretend to play.  
Future plans include the ability to create many bots, functioning on different browsers and possibly a better interface.

### Testing environment
This project was tested with ***python 3.14.4*** on ***Ubuntu 26.04.1 LTS*** with ***Brave*** browser. 
It is acknowledged by the creator that this project without any code modifications will only work with *Brave* browser and probably only on *linux*. 
This will hopefully change soon.
